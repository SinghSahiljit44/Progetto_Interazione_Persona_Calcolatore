\section*{Capitolo 1}
\section{Descrizione del Sistema}

L'applicazione presa in esame in questo progetto è una \textbf{web application bancaria} che fornisce funzionalità di home banking e gestione dei servizi bancari di base. L'applicazione si propone di coprire tre principali aree di utilizzo, ciascuna destinata a una specifica categoria di utenti:

\subsection{Categorie di Utenti}

\textbf{Clienti}\\
I clienti della banca possono accedere a un'interfaccia intuitiva per gestire le principali operazioni bancarie online, come:
\begin{itemize}
	\item Visualizzazione del saldo e della lista movimenti;
	\item Bonifici e trasferimenti di denaro;
	\item Gestione dei propri dati anagrafici.
\end{itemize}
\textbf{Employee}\\
I dipendenti della banca possono accedere a un pannello dedicato che consente di:
\begin{itemize}
	\item Visualizzare e modificare i dati dei clienti;
	\item Gestire operazioni richieste dai clienti in filiale;
	\item Gestire le credenziali per l'accesso dei clienti.
\end{itemize}
\textbf{Admin}\\
Gli admin hanno accesso completo alla gestione dell'utenza e delle funzionalità del sistema, con la possibilità di:
\begin{itemize}
	\item Creare, modificare e cancellare account (clienti e employee);
	\item Gestire le assegnazioni fra clienti e employee;
	\item Monitorare le attività del sistema.
\end{itemize}

\subsubsection{Schermate Employee}
La dashboard degli employee presenta 4 operazioni principali:
\begin{itemize} 
	\item "I miei Clienti": Permette di visualizzare il sottoinsieme dei clienti della banca assegnati all'addetto
	\item "Operazioni universali": Operazioni che l'addetto può eseguire su qualunque cliente della banca (prelievi e depositi)
	\item "Transazioni": Sono le transazioni dei clienti che l'addetto gestisce
	\item "Recupero credenziali": Opzione che permette al cliente di recarsi in banca e richiedere il reset al proprio referente
\end{itemize}
\begin{figure}[htbp]
	\centering
	\includegraphics[width=0.9\textwidth]{dashboard_employee}
	\caption{Dashboard employee}
	\label{fig:dashboard_employee}
\end{figure}
\clearpage
Nella sezione "I miei Clienti" per ogni cliente è presente una riga con:
\begin{itemize}
	\item Alcune informazioni sul cliente
	\item Numero di conto e saldo del cliente 
	\item Stato del conto e data di attivazione
	\item 4 shortcuts:
		\begin{itemize}
			\item Visualizza: Presenta una schermata con tutti i dettagli del cliente e tutte le operazioni che si possono effettuare sul cliente  
			\item Modifica: Permette di modificare le informazioni personali del cliente
			\item Deposito: Per effettuare un deposito in filiale
			\item Bonifico: Per effettuare un bonifico tramite l'addetto in banca 
		\end{itemize}
\end{itemize}

\subsubsection{Schermate Admin}
La dashboard admin contiene 6 sezioni principali:
\begin{itemize}
	\item Gestione utenti: Vedi dopo
	\item Transazioni: Sezione con le transazioni di tutti i clienti della banca 
	\item Assegnazioni: Sezione per gestire le assegnazioni tra cliente e employee 
	\item Recupero credenziali: Sezione per resettare username e password per ogni cliente 
	\item Report: Sezione con report e statistiche 
	\item Conti: Lista di tutti i clienti e i loro conti con la possibilità di bloccare/sbloccare il conto
\end{itemize}
\begin{figure}[htbp]
	\centering
	\includegraphics[width=0.9\textwidth]{dashboard_admin}
	\caption{Dashboard admin}
	\label{fig:dashboard_admin}
\end{figure}
\clearpage
\noindent
Nella sezione gestione utenti per ogni utente della banca abbiamo al più 4 shortcut:
\begin{itemize}
	\item Se l'utente è un admin:
	\begin{itemize}
		\item Si può visualizzare le informazioni personali 
	\end{itemize}
	\item Se l'utente è un employee:
	\begin{itemize}
		\item Si può visualizzare le informazioni personali 
		\item Si può modificare le informazioni personali 
		\item Si può eliminare l'employee
	\end{itemize}
	\item Se l'utente è un cliente:
	\begin{itemize}
		\item Si può visualizzare le informazioni personali
		\item Si può modificare le informazioni personali 
		\item Si può eliminare il cliente
		\item Si può attivare il conto di un cliente se non ancora attivo 
		\item Si può Bloccare/Sbloccare un contoa
	\end{itemize}
\end{itemize}
